# Redacted Follow60 reference corpus

This directory records hashes and redacted summaries only. Raw production logs,
XML and screenshots remain in their protected operational locations and are not
duplicated into Git. No username, account UUID, candidate identity, token,
credential or device serial is stored here.

The corpus covers the final canary lineage used to certify Follow, Mute,
PostGrid/reveal, absolute top-left, V5, Like, Return CT, cycle persistence and
the ten-cycle evaluation barrier. Mainline removes only the canary admission
control and barrier; it does not change those physical-action contracts.
