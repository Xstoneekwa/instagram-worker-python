# Golden Evidence Registry

This directory stores versioned, reviewable evidence manifests for physically
validated worker baselines. Evidence directories are immutable once tagged;
later improvements receive a new version instead of rewriting an existing one.

Available baselines:

- [Follow 85s V1](./follow-85s/README.md) - 20 verified physical cycles on
  runtime `ff99db6d7de48d75ede439c704e770feaaec6b7c`.
