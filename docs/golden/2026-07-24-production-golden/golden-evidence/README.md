# Golden evidence

Sanitized evidence supporting the **Golden Production Checkpoint — Phone Farm
2026-07-24**.

The evidence is intentionally split from the operating documentation:

- [SHA](SHA.md)
- [release](RELEASE.md)
- [tests](TESTS.md)
- [captures](CAPTURES.md)
- [request and run IDs](RUN_REQUEST_IDS.md)
- [dispatcher](DISPATCHER.md)
- [runtime](RUNTIME.md)
- [cross-repository artifacts](CROSS_REPO.md)

This folder contains no secret, credential, browser session, raw device serial,
account ID or database export. Raw operator captures remain outside Git because
they contain operational identifiers. Their conclusions are recorded in
sanitized form in [CAPTURES.md](CAPTURES.md).

The documentation commit and annotated tag are created after these files are
validated. Their final IDs are recorded in the tag annotation and in the root
[release registry](../../../RELEASE_REGISTRY.md).
